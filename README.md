# 🐍 Snake Autobattler: The Radiant Engine
*> "The soil does not remember the victor, but the chronicler remembers the struggle."*

Welcome to a persistent experiment in **procedural narrative synthesis**. This project explores how to turn raw simulation data into meaningful, dramatic history.

## 🌟 The Radiant Evolution (v13.0)
**Current Version: v13.0 "The Radiant Architect"**

In this latest iteration, the engine has become "Meta-Agentic". It knows it is a simulation and exposes its own internal logic through interactive tools.

### The Problem -> Tool Methodology
This project evolved by identifying narrative disconnects and building specific tools to solve them:

1.  **Problem**: *Narrative felt detached from the math.*
    -   **Tool**: `v4.0 Saga Engine` introduced a dramatic-arc classifier to group raw events into meaningful story beats.
2.  **Problem**: *Manual agency was tedious in an autobattler.*
    -   **Tool**: `v7.0 Personality Matrix` automated decision-making based on trait-driven causality.
3.  **Problem**: *The simulation was opaque to the user.*
    -   **Tool**: `v13.0 Hall of Designers` & `Radiant Toy` created a feedback loop for interactive mechanical auditing.
4.  **Problem**: *The UI felt static and "app-like".*
    -   **Tool**: `SnakeSkinLayout` (v13) introduced a living, breathing hex-grid interface with organic SVG navigation.

## 🛠️ Architecture
-   **Sim Layer**: Deterministic physics and personality-driven AI.
-   **Narrative Layer**: Cross-genre prose synthesis with "Genre Bleed" mechanics (`narrate.ts`).
-   **Visual Layer**: SVG path-morphing and WebGL iridescence (`SnakeSkinLayout.tsx`).
-   **Portfolio Meta**: A "Version Archive" allowing historical playback of previous engine architectures.
